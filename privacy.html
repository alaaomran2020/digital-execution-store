الخصوصية

سياسة الخصوصية

المتجر مصمم بأقل قدر ممكن من جمع البيانات، وبدون إنشاء حساب إلزامي للشراء الحالي.

الشراء والدفع

الموقع لا يخزن بيانات بطاقات أو PIN أو OTP. تأكيد الدفع الحالي يتم يدويًا عبر Vodafone Cash وWhatsApp، ولا نطلب بيانات سرية للمحفظة.

WhatsApp

أي بيانات أو إثبات دفع ترسله عبر WhatsApp يتم التعامل معه لغرض متابعة طلبك أو استفسارك، كما يخضع استخدام WhatsApp لسياسات الخدمة نفسها.

الأدوات والنماذج

الأدوات العامة مثل Inventory Health Check تنفذ الحساب داخل المتصفح. عند اختيار إرسال النتيجة على WhatsApp يتم إنشاء الرسالة على جهازك قبل فتح WhatsApp.

ReStock Desk

النسخة الحالية تعمل محليًا وتخزن بيانات التشغيل في Local Storage داخل متصفح المستخدم، بدون Backend أو API خاص بالمنتج. مسح بيانات المتصفح قد يؤدي إلى فقد البيانات، لذلك يُنصح بعمل Backup دوري.

القياس التقني

قد تسجل صفحات المتجر أحداث استخدام تقنية مثل مشاهدة المنتج والضغط على أزرار الشراء داخل طبقة قياس الواجهة. هذه الأحداث لا تمثل تأكيد دفع، ولا يتم اعتبار عملية شراء مؤكدة إلا بعد التحقق التجاري.
