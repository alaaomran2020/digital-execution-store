# Digital Execution — Visual Commerce System v1

## Brand direction
Minimal Digital Commerce System. الانطباع المقصود: منتجات رقمية عملية، واضحة، منظمة، ومصممة لتنجز مهمة حقيقية.

**Principles:** Clarity · Execution · Utility · Trust · Digital Precision.

## Core tokens
- Navy: `#0B1220`
- Brand Blue: `#2563EB`
- Background: `#F8FAFC`
- Surface: `#FFFFFF`
- Text: `#111827`
- Muted: `#64748B`
- Border: `#E2E8F0`
- Success: `#15803D`
- Warning: `#B45309`
- Error: `#B91C1C`

Spacing: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 80 / 96.
Radius: 8 / 12 / 16.
Shadows: restrained, commerce-first; no decorative glow.

## Typography
Primary stack: Alexandria → IBM Plex Sans Arabic → Tahoma → Arial.
Use one family system. Display and H1 use responsive `clamp()`; body remains 16px+ with 1.7–1.8 line-height.

## Logo usage
The existing **DE** mark remains the compact brand mark. It is used consistently with the Digital Execution wordmark.
- Primary / horizontal: mark + Digital Execution.
- Compact: DE mark only.
- Dark surfaces: white mark / light text.
- Light surfaces: navy mark / navy text.
- Monochrome: single navy or white.
- Clear space: at least 25% of mark width.
- Minimum mark size: 28px digital.
- No gradients, shadows, rotation, distortion, or per-page variants.

## Product visual system
Every product should expose six deliverables when needed: Product Cover, Store Card, Hero, Preview, Social Preview, OG Image.
The product itself is the visual hero. ReStock Desk uses real UI captures. Career Kit uses clean document/workflow compositions. Product personality may vary, but brand framing, spacing, navy/blue accents, captions, borders, and image ratios stay consistent.

## Components
Buttons: Primary (purchase/open product), Secondary (preview/details), Tertiary (text link).
Cards: single border, 12–16px radius, no decorative glow.
Product cards: visual first, name, one-line benefit, type, price, one CTA.
Trust: structured facts, not badge walls.

## Accessibility
Target WCAG 2.2 AA. 44px+ touch targets, clear focus rings, semantic labels, reduced-motion respect, sufficient contrast in light and dark color schemes.

## Scalability
Categories are displayed only when populated. Current visible categories: Business and Career. Future categories can inherit the same card/token system without redesigning the store.
