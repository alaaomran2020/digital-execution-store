# Digital Execution — SEO Keyword Map

آخر تحديث: 23 سبتمبر 2026

## الهدف
توسيع الكلمات المفتاحية حول المنتجين التجاريين الحاليين بدون Cannibalization، وبناء مسار واضح:
Search → Guide/Tool → Product → WhatsApp/Purchase.

## قواعد التنفيذ
- كل صفحة لها Primary Keyword واحدة واضحة.
- الكلمات القريبة دلاليًا تظل Secondary Keywords داخل نفس الصفحة بدل إنشاء صفحات متشابهة.
- لا يتم إنشاء صفحة جديدة لمجرد اختلاف صياغة الكلمة.
- صفحات المنتج تستهدف Commercial / Transactional intent.
- صفحات الأدلة تستهدف Informational intent وتربط بالمنتج المناسب.
- الأدوات المجانية تستهدف Tool / Lead intent.
- لا نستخدم ادعاءات مثل "أفضل" أو "رقم 1" بدون دليل مستقل.

## ReStock Cluster
**Core semantic field:** إدارة المخزون، مخزون المحلات، النواقص، حد إعادة الطلب، الجرد، مخزون الأمان، نفاد المخزون، الموردين، المخزون الراكد، كارت الصنف.

الكلمات التي ظهرت بوضوح في نتائج البحث الحالية تشمل إدارة المخزون للمحلات، حد إعادة الطلب، الجرد الدوري، حركة الصنف، ونفاد/نقص المخزون. المنافسة الحالية تجمع هذه الموضوعات تحت أدلة شاملة وبرامج POS/ERP، لذلك Digital Execution يركز على الاستخدام الأبسط للمحل الصغير بدل منافسة ERP كامل.

## Career Cluster
**Core semantic field:** CV ATS، سيرة ذاتية ATS، CV للخريجين، CV لأصحاب الخبرة، الكلمات المفتاحية، الإنجازات، LinkedIn Profile، Cover Letter، Job Tracker، Interview Prep.

نتائج البحث الحالية تكرر بوضوح: ATS، الكلمات المفتاحية من Job Description، قوالب بسيطة قابلة للقراءة، فصل محتوى Fresh Graduate عن Experienced، LinkedIn، وCover Letter. لذلك تم توسيع الـCluster فعليًا ليشمل Summary، Skills، Achievements، ATS Keywords، وSTAR Interview مع الحفاظ على Intent مستقل لكل صفحة.

## الصفحات المتخصصة المنفذة
ReStock: منع نفاد المخزون → مخزون الأمان → المخزون الراكد → تجميع طلبات الموردين.

Career: Summary للـCV → المهارات في السيرة الذاتية → الإنجازات في CV → كلمات ATS → STAR Interview.

الحالة: جميعها Live داخل الـCluster بعد اجتياز Store QA وStructured Data وSitemap وInternal Linking.

## Cannibalization Guard
- "إدارة مخزون المحلات" تبقى للـPillar؛ صفحة المنتج تستهدف "برنامج إدارة المخزون للمحلات".
- "CV بنظام ATS" تبقى للـPillar؛ صفحة المنتج تستهدف Career Kit والقوالب/الأدوات التجارية.
- "CV للخريجين" و"CV لأصحاب الخبرة" يظلان منفصلين بسبب اختلاف الجمهور والنية.
- "LinkedIn" و"Cover Letter" يظلان صفحات مستقلة لأنهما مهام مختلفة عن كتابة CV.
