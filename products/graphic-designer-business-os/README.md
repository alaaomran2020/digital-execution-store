# باكدج إدارة أعمال مصمم الجرافيك الاحترافي — Graphic Designer Business OS v1.0.0

تاريخ البداية: 26 سبتمبر 2026

## العميل المستهدف
مصممو الجرافيك المستقلون والاستوديوهات الصغيرة التي تدير العملاء وطلبات التصميم والتسعير والمشاريع والتعديلات والتحصيل بنفسها.

## دورة العمل
عميل محتمل → عميل → طلب تصميم / Brief → عرض سعر → مشروع تصميم → مهام → تسليم → تعديلات → فاتورة → تحصيل → ربحية → أرشيف.

## الوحدات
لوحة التحكم، العملاء المحتملون، العملاء، طلبات التصميم والـBrief، عروض الأسعار، مشاريع التصميم، المهام، التسليمات والتعديلات، الفواتير، المدفوعات، المصروفات، حاسبة التسعير، الربحية، التقارير، الجودة، الأرشيف، النسخ الاحتياطي والاستعادة.

## حدود المنتج
نظام إدارة أعمال محلي يعمل من المتصفح بدون API أو خادم أو اشتراك خارجي. لا ينشئ التصميمات ولا يستبدل برامج التصميم، وليس نظام فوترة ضريبية معتمدًا.
