# باكدج الفريلانسر الاحترافي — Freelancer Business OS v1.0.0

تاريخ البداية: 25 سبتمبر 2026

## العميل المستهدف
المستقلون الذين يديرون العملاء والمشاريع والتسعير والتحصيل بأنفسهم.

## دورة العمل
عميل محتمل → عميل → Brief → عرض سعر → مشروع → مهام وتسليمات → فاتورة → تحصيل → ربحية → أرشيف.

## الوحدات
لوحة التحكم، العملاء المحتملون، العملاء، Briefs، عروض الأسعار، المشاريع، المهام، التسليمات، الفواتير، المدفوعات، المصروفات، حاسبة التسعير، الربحية، التقارير، الجودة، الأرشيف، النسخ الاحتياطي والاستعادة.

## حدود المنتج
نظام محلي يعمل من المتصفح بدون API أو خادم أو اشتراك خارجي، وليس نظام فوترة ضريبية معتمدًا.
