# باكدج المدرس الاحترافي — v1.0.0

تاريخ البداية: 25 سبتمبر 2026

## العميل المستهدف
المعلمون والمدرسون الخصوصيون ومقدمو المجموعات التعليمية الذين يحتاجون نظامًا عربيًا بسيطًا لإدارة الطلاب والمجموعات والحضور والواجبات والتقييمات والتحصيل المالي.

## دورة العمل
الطلاب → المجموعات → الجدول والحصص → الحضور → الواجبات والتقييم → الرسوم والتحصيل → المتابعة → إغلاق الفترة.

## الوحدات
لوحة التحكم، الطلاب، المجموعات، الحصص والجدول، الحضور، الواجبات، التقييمات، الرسوم والمدفوعات، المتابعة، التقارير، فحص الجودة، الأرشيف.

## حدود المنتج
أداة تنظيم وإدارة تعليمية وليست منصة تعليم إلكتروني، ولا تولد محتوى دراسيًا أو إجابات للطلاب تلقائيًا، ولا تحتاج API أو خادمًا.
