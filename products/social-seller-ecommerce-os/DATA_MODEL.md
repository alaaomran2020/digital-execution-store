# Data Model

CUSTOMER → PRODUCT → ORDER → FULFILLMENT / SHIPPING → COLLECTION / RETURN → EXPENSE → PROFITABILITY → ARCHIVE

## نموذج التنفيذ في v1.0.0
- بيانات التجهيز والشحن والتحصيل محفوظة داخل سجل الطلب، وليست كيانات مستقلة.
- كل طلب مرتبط بعميل ومنتج واحد (SKU واحد لكل طلب في الإصدار الحالي).
- الطلب يخصم المخزون عند الإنشاء مع منع تجاوز الرصيد.
- إلغاء الطلب يعيد المخزون مرة واحدة ولا يسمح بإعادة فتح الطلب الملغي.
- المرتجع مرتبط بطلب صالح، ولا يمكن أن تتجاوز كميته الكمية المباعة.
- المرتجع القابل لإعادة التخزين يعيد الكمية للمخزون ويعكس تكلفة البضاعة للكمية المعادة.
- المرتجع التالف لا يعكس تكلفة البضاعة.
- الربحية = صافي المبيعات بعد الخصم والاستردادات - تكلفة البضاعة - تكلفة الشحن الفعلية - المصروفات المرتبطة.
