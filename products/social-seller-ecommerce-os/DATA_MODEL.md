# Data Model

CUSTOMER → PRODUCT → ORDER → SHIPMENT → PAYMENT / RETURN → EXPENSE → PROFITABILITY → ARCHIVE

## قواعد النزاهة
- كل طلب مرتبط بعميل.
- كل شحنة مرتبطة بطلب صالح.
- لا يتجاوز التحصيل إجمالي الطلب.
- المرتجع يخفض صافي الإيراد.
- لا يغلق الطلب قبل حسم الشحن والتحصيل/المرتجع.
- الربحية = صافي الإيراد بعد المرتجعات - تكلفة البضاعة - المصروفات المرتبطة.
