# باكدج إدارة البيع أونلاين الاحترافي

الإصدار: 1.0.0

نظام تشغيل محلي للبائعين على السوشيال ميديا والمتاجر الصغيرة، يربط دورة العمل:
استفسار → عميل → منتج → طلب → تجهيز → شحن → تحصيل → مرتجع → مصروف → ربحية → أرشيف.

## الوظائف الأساسية
- لوحة مؤشرات للمبيعات والتحصيل والمصروفات وصافي النقد.
- متابعة الاستفسارات والعملاء ومصادر الطلبات.
- سجل المنتجات والتسعير والتكلفة.
- إدارة الطلبات وحالات التجهيز والشحن والتسليم.
- متابعة التحصيل والمدفوعات والمبالغ المستحقة.
- تسجيل المرتجعات والمصروفات.
- تقارير ربحية حسب الطلب.
- فحص جودة وتنبيهات للطلبات المتأخرة وغير المحصلة.
- Backup / Restore محلي.

لا يحتاج API أو خادم أو اشتراك شهري. البيانات تحفظ محليًا في المتصفح ويجب أخذ نسخة احتياطية دوريًا.
