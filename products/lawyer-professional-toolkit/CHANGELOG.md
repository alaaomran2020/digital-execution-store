# سجل إصدارات باكدج المحامي الاحترافي

## 1.0.0 — 25 سبتمبر 2026
- إصلاح دورة الإدخال لتشمل الجلسات والمستندات والإجراءات وإغلاق القضية.
- فرض سلامة العلاقات: لا قضية بدون عميل موجود، ولا سجل تابع بدون قضية موجودة.
- إضافة تحذير عند إغلاق قضية مع رصيد أتعاب مفتوح وتحديث حالة القضية وتاريخها عند الإغلاق.
- إطلاق الإصدار التجاري الأساسي كنظام لإدارة العمل القانوني اليومي.
- اعتماد القضية كمحور ربط بين العميل والجلسات والمهام والمستندات والإجراءات والحركات المالية.
- إضافة لوحة تحكم ومركز تنبيهات وفحص جودة قبل الإغلاق.
- إضافة متابعة الأتعاب والدفعات والمتبقي ومصروفات القضية دون تحويل الباكدج إلى نظام محاسبي.
- إضافة سجل إغلاق وأرشفة يحفظ نتيجة القضية والموقف المالي والمستندات النهائية.
- تثبيت حدود المنتج: لا مكتبة عقود أو قوانين أو أحكام، ولا توليد مذكرات أو استشارات قانونية آلية.
