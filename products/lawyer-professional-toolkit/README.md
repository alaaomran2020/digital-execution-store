# باكدج المحامي الاحترافي v1.0.0

نظام عربي محلي لإدارة العمل القانوني اليومي.

## التشغيل
افتح ملف app/index.html في متصفح حديث. تحفظ البيانات محليًا في المتصفح.

## دورة العمل
العميل → القضية → الجلسات والمهام والمستندات والإجراءات → الأتعاب والمصروفات → الإغلاق.

## الحدود
أداة تنظيم وإدارة وليست مصدرًا للاستشارة القانونية أو بديلًا عن المراجعة المهنية.
