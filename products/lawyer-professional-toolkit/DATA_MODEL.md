# نموذج البيانات — باكدج المحامي الاحترافي v1.0.0

## مفتاح الربط
CLIENT_ID → CASE_ID → SESSION/ACTION_ID → DOCUMENT_ID → FIN_TXN_ID

## الكيانات الأساسية
- العملاء: CLIENT_ID، الاسم، النوع، التواصل، حالة الملف، الملاحظات.
- القضايا: CASE_ID، CLIENT_ID، الرقم الرسمي، المحكمة، الدائرة، النوع، الخصوم، المحامي المسؤول، الحالة، آخر تحديث.
- الجلسات: SESSION_ID، CASE_ID، التاريخ، القرار السابق، المطلوب، الجلسة القادمة، حالة المتابعة.
- المهام: TASK_ID، CASE_ID، المسؤول، الأولوية، الموعد النهائي، الحالة.
- المستندات: DOCUMENT_ID، CASE_ID، النوع، التاريخ، الوصف، النسخة، مكان الحفظ، حالة المراجعة.
- الإجراءات: ACTION_ID، CASE_ID، التاريخ، نوع الإجراء، الوصف، المسؤول، النتيجة.
- الحركات المالية: FIN_TXN_ID، CASE_ID، CLIENT_ID، النوع، القيمة، التاريخ، الاستحقاق، الحالة، البيان.
- الإغلاق: CASE_ID، النتيجة، تاريخ الإغلاق، الموقف المالي، المستندات النهائية، ملاحظات الإغلاق.

## حالات القضية
جديدة → نشطة → معلقة → تحت المراجعة → جاهزة للإغلاق → مغلقة → مؤرشفة.

## حالات المهمة
جديدة → قيد التنفيذ → مكتملة → متأخرة → ملغاة.

## حالات المستند
مطلوب → مستلم → تحت المراجعة → معتمد → ناقص/يحتاج استكمال.

## القواعد المالية
الأتعاب المتبقية = الأتعاب المتفق عليها - إجمالي دفعات العميل.
صافي موقف القضية = إجمالي المحصل - مصروفات القضية.
لا تُعامل هذه الحسابات كدفتر أستاذ أو نظام محاسبي.

## قواعد التنبيه
جلسة قريبة، مهمة متأخرة، مستند ناقص، أتعاب مستحقة، قضية بلا تحديث، وقضية تحتاج مراجعة قبل الإغلاق.
