# باكدج المهندس الزراعي الاحترافي — v1.0.0

تاريخ البداية: 25 سبتمبر 2026

## النطاق والعميل المستهدف
نظام إدارة وتشغيل يومي للمهندس الزراعي ومدير المزرعة والمشروعات الزراعية الصغيرة والمتوسطة. المنتج ينظم الحقول والمحاصيل والعمليات والمدخلات والري والتسميد والمكافحة والحصاد والمصروفات والمخزون في مكان واحد. ليس مرجعًا للإرشاد الزراعي ولا بديلًا عن توصية مهندس مختص.

## دورة العمل
تسجيل المزرعة والحقل → الموسم والمحصول → خطة العمليات → الري والتسميد والمكافحة → العمالة والمدخلات والمصروفات → المتابعة الميدانية → الحصاد والإنتاجية → إغلاق الموسم.

## الوحدات الأساسية
1. لوحة التحكم.
2. المزارع والحقول.
3. المواسم والمحاصيل.
4. العمليات الزراعية والمهام.
5. الري.
6. التسميد.
7. المكافحة والملاحظات الميدانية.
8. المخزون والمدخلات.
9. العمالة والمصروفات.
10. الحصاد والإنتاجية.
11. الأرشيف وإغلاق الموسم.
12. فحص الجودة.

## نموذج البيانات
FARM_ID → FIELD_ID → SEASON_ID → OPERATION_ID
ويرتبط SEASON_ID كذلك بـ IRRIGATION_ID / FERTILIZATION_ID / PROTECTION_ID / INPUT_TXN_ID / EXPENSE_ID / HARVEST_ID.

## لوحة التحكم
المواسم النشطة، المساحة المزروعة، عمليات اليوم، المهام المتأخرة، الري القادم، المدخلات منخفضة المخزون، مصروفات الموسم، كمية الحصاد، متوسط الإنتاجية.

## التنبيهات
عملية متأخرة، موعد ري قريب، مهمة غير مكتملة، مخزون منخفض، مصروف غير مصنف، موسم بلا تحديث، موسم يحتاج مراجعة قبل الإغلاق.

## حدود v1.0.0
لا تشخيص آلي للأمراض، لا جرعات مبيدات/أسمدة كتوصية مهنية، لا توقعات مناخية، لا أسعار سوق حية، لا API أو Backend.
