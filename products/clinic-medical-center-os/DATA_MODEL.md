# Data Model

PATIENT → APPOINTMENT → VISIT / SERVICE → COLLECTION → EXPENSE → FOLLOW-UP → REPORTS → ARCHIVE

- المرضى: بيانات تعريف وتواصل إدارية فقط.
- الموعد مرتبط بمريض وتاريخ ووقت وخدمة وحالة.
- الزيارة مرتبطة بموعد واحد، وتسجل قيمة الخدمة والمدفوع والمتبقي.
- المصروفات تشغيلية مستقلة.
- المتابعة إدارية فقط ولا تتضمن تشخيصًا أو توصية طبية.
- لا توجد حقول لتشخيص أو وصفة أو نتائج فحوصات أو ملف طبي.
