# باكدج إدارة العيادات والمراكز الاحترافي

الإصدار: 1.0.0

نظام تشغيل محلي لإدارة المرضى إداريًا والمواعيد والزيارات والخدمات والتحصيل والمصروفات والمتابعة والتقارير.

## الوظائف الأساسية
- لوحة مؤشرات للمواعيد والتحصيل والمصروفات.
- سجل المرضى وبيانات التواصل الإدارية.
- إدارة المواعيد وحالات الحضور والإلغاء وعدم الحضور.
- تسجيل الزيارات والخدمات وقيمة الخدمة والمدفوع والمتبقي.
- المصروفات التشغيلية والمتابعة الإدارية.
- تقارير تشغيلية ومالية وفحص جودة.
- Backup / Restore محلي.

## حدود النطاق
لا يخزن تشخيصات أو وصفات أو نتائج فحوصات ولا يقدم قرارات طبية، ولا يعد نظام سجلات طبية إلكترونية. لا يحتاج API أو خادم أو اشتراك شهري.
